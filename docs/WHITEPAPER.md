# TwinPDF Product Whitepaper

## 0. One sentence
TwinPDF is a personal bilingual lecture-study workspace: read English PDF slides on the left, read a Chinese handout on the right, ask an always-on AI assistant about selected text, and export a personal Markdown sub-lecture at the end.

## 1. Why this exists
The user studies difficult English course PDFs. A generic PDF reader is not enough because:

- lecture slides are English, but exam preparation needs bilingual understanding;
- generated Chinese handouts are useful, but they must stay aligned with the original slides;
- selecting text in rendered PDFs is annoying, but showing selected text as ordinary HTML lets browser translation work quickly;
- repeated questions happen often: “这句话到底想表达什么？”, “为什么要这样定义？”, “这个公式里的每一项是什么意思？”;
- one-off AI answers are easily lost; the useful answers should become a personal sub-handout.

TwinPDF therefore focuses on a narrow loop:

```text
read → select → browser-translate → ask → save → summarize
```

## 2. Product philosophy
TwinPDF should feel like a small craft tool that stays beside the user during self-study. It should not feel like a corporate dashboard.

Keywords:

- calm;
- symmetric;
- fast;
- personal;
- low-friction;
- no hidden state;
- warm AI explanation.

The product should be “boring in the best way”: predictable, quiet, and always helpful.

## 3. Core interface

### Left: English PDF
The left side is the source of truth. It displays the original lecture PDF. Users can load, scroll, zoom, navigate pages, and select text.

### Right: Chinese handout
The right side displays the Chinese lecture guide. It may be a Markdown file generated by GPT/DeepSeek in a separate workflow. TwinPDF does not need to generate the whole handout in the first MVP, but it must let the user open and read it.

### Bottom: AI Assist
The bottom assistant is the product’s soul. It is resizable, always available, and designed around selected text:

1. **已选原文** — raw selected English text.
2. **浏览器翻译区** — ordinary HTML surface for browser/extension translation.
3. **AI解释** — warm contextual explanation.
4. **继续追问** — input field for follow-up questions.
5. **锁定输入** — preserve repeated question across selections.
6. **锁定子讲义** — auto-save successful answers.
7. **加入成功** — green confirmation for saved entries.

## 4. The learning memory idea
TwinPDF is not just a reader. It remembers how the user learned.

A selected passage plus question plus answer is saved as a learning event:

```text
page + original text + browser translation surface + user's question + AI answer + timestamp + right-handout context
```

At the end, those learning events are summarized into a personal sub-lecture. This is not the original lecture and not the generic handout. It is the user’s own “what I struggled with and how I resolved it” document.

## 5. Why local workspace folders
The user does not want important state scattered in browser cache. TwinPDF therefore asks the user to choose a local workspace folder. Inside it, the app stores:

- source PDFs;
- handouts;
- sentence indexes;
- AI page labels;
- question logs;
- personal sub-handout;
- final exports.

The browser may remember only an opaque folder handle for “continue last workspace.” All meaningful learning data lives in files the user can inspect.

## 6. AI behavior
AI should not sound like a dead documentation generator. It should behave like a strong TA who is synchronized with the user.

Desired tone:

- “这句话其实是在说……”;
- “你可以把它想成……”;
- “这里最容易混的点是……”;
- “如果考试问这个，通常会考……”;
- “先别被公式吓到，核心是……”;

Use bullets only when they help. Prefer short paragraphs and analogies.

## 7. What is intentionally out of scope
Before DONE, do not build:

- accounts;
- cloud sync;
- social sharing;
- tag systems;
- bookmark management;
- complex dashboards;
- multi-user collaboration;
- general PDF editor features.

## 8. Final export vision
The final Markdown sub-lecture should include:

```markdown
# 个人子讲义：<课程/章节名>

## 本节核心问题

## 我问过的问题

## 易错概念

## 句子级解释

## 公式与定义

## 考前复习清单

## 原始问答日志
```

It should preserve enough source references: page number, original sentence, question, answer.
